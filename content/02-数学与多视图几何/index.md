# 数学与多视图几何

本模块记录三维重建算法所需的数学知识。

## 学习内容

### 01. 数学基础
- 线性代数
- 矩阵分解
- 李群与李代数

### 02. 多视图几何
- 相机成像模型
- 坐标变换
- 极线几何
- 三角化
- PnP

### 03. 三维重建
- Structure from Motion
- Multi-View Stereo
- Bundle Adjustment

### 04. 数值优化
- Jacobian
- Gauss-Newton
- Levenberg-Marquardt

## 阶段目标

理解 SfM/MVS 的核心原理，并使用 C++ 独立实现基础几何算法。
