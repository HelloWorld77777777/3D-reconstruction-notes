# 工程项目

记录个人三维重建项目的设计、实现、测试和性能优化过程。

## 项目一：Mini-Geometry

使用 C++、Eigen 和 Ceres 实现：

- 三维坐标变换
- 相机投影
- 重投影误差计算
- 三角化
- 非线性优化

## 项目二：Gaussian-CUDA-Toolkit

使用 C++/CUDA 实现：

- Gaussian Filtering
- Gradient Statistics
- GPU Kernel
- PyTorch Extension
- Performance Benchmark

## 项目记录规范

每个项目尽量包含：

1. 项目目标
2. 技术原理
3. 实现过程
4. 测试结果
5. 问题与改进
